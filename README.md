# Claude Motion

Motion-graphics / YouTube video toolkit for Claude Code.

## Installed skills
- `remotion-dev/skills` (in `.agents/skills`, linked into `.claude/skills`) — Remotion best practices: animations, springs, transitions, captions, audio, 3D.

## Render engine
Remotion (React → MP4). Start a project: `npx create-video@latest`
Render: `npx remotion render`

## Connectors used alongside
- ElevenLabs — voiceover
- vidIQ — titles, keywords, thumbnails
